Важно: **все пять файлов этого патча целиком входят в патч v20** — там они лежат

## Что изменилось

**Веса балла пересобраны.** Было 50/25/15/10 (сумма подписанных спецификаций,
конверсия, просрочка, количество КП). Стало пять составляющих:

| Составляющая | Вес |
|---|---|
| Ожидаемые платежи | 35 |
| Сумма подписанных спецификаций | 30 |
| Конверсия решённых КП | 25 |
| Платежи без просрочки | 5 |
| Количество КП | 5 |

Просрочка потеряла вес: она говорит о дисциплине платежей клиента, а не о силе
партнёра, и на 15 весах утягивала вниз партнёров с крупными сделками. Главным
стал будущий денежный поток — ожидаемые платежи по подписанным спецификациям.

**Ожидаемые платежи считаются от выбранного года и дальше**, а не только внутри
года: платёж по спецификации 2024-го, ожидаемый в 2026-м, относится к обеим
картинам. Договор при переходе на новый год больше не обнуляется.

**Балл сглажен по трём годам** с весами 75 / 20 / 5 (текущий, минус один, минус
два). Один слабый или один удачный год больше не переставляет партнёра через
полтаблицы — рейтинг показывает тренд, а не срез.

**Цифры нормируются на лидера**: у лучшего партнёра выборки 100.

**Попапы со статистикой** раскрыты под кнопками показателей; клик по количеству
КП открывает список по годам.

## Руками

1. Скопировать файлы поверх проекта.
2. `php artisan view:clear && php artisan cache:clear`.
3. `osmo-metronic.js` кэшируется браузером — при необходимости поднять версию
   в подключении layout'а.

## Чек-лист проверки

- [ ] `/analytics/partners`: в разбивке балла пять составляющих с весами
      35/30/25/5/5.
- [ ] Балл партнёра с провальным одним годом не падает в самый низ — видно
      сглаживание.
- [ ] Ожидаемые платежи при выборе года 2024 включают платежи 2025–2026.
- [ ] Клик по цифрам показателей открывает попап; по количеству КП — список
      по годам.
- [ ] `/partners/detail`: у спецификации видна её дата и номера прикреплённых КП.
- [ ] Отрицательный срок (КП позже спецификации) показан оранжевым.

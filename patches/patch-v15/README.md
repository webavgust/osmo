## Анализ скидок · `/analytics/discounts`

Скидка в КП двухступенчатая и живёт по позициям: процент заказчику снимается
с прайса, процент партнёру — с уже уменьшенной цены. В карточке КП это видно
по одному предложению; здесь — по всем сразу.

Формула повторена из карточки один в один, чтобы цифры сходились, включая то,
что у платформы, ПО и нейросервисов процент партнёра общий на весь вариант, а
у работ — свой на каждой позиции. Считается последний созданный вариант
последней редакции — тот, что ушёл заказчику.

**Показатели сверху:** прайс до скидок, скидка заказчику, скидка партнёру,
итог и совокупный процент. Суммы приведены к рублям — в выборке разные валюты.

**Таблица:** прайс, обе скидки в деньгах и процентах, итог, совокупный процент
и разбивка по четырём блокам отдельными плашками. Суммы строки — в валюте
своего КП, проценты сравнимы между собой.

**Что выделяется красным.** Три правила:

- совокупная скидка выше **40%** (`HARD_LIMIT_P`);
- скидка выше среднего уровня своего грейда более чем на **5 п.п.**
  (`GRADE_ALERT_PP`) — средний уровень считается по самой выборке,
  средневзвешенно по прайсу, чтобы одно мелкое КП не задирало планку грейда;
- скидка заказчику есть, а партнёрской нет — обычно недозаполненный вариант.

Оба порога — константы в `DiscountAnalysisService`, меняются одной строкой.

Отбор: год (по умолчанию последний — иначе выборка тянет все позиции всех КП),
партнёр, статус КП, поиск и галка «только выделенные».

## Скоринг партнёров · `/analytics/partners`

Партнёра видно по четырём вещам: доводит ли он КП до сделки, на какие деньги,
платят ли по его договорам вовремя и сколько он просит скидки.

| Столбец | Что показывает |
|---|---|
| Балл | 0–100 и буква A…E |
| КП | всего, ниже — выиграно / проиграно / в работе |
| Конверсия | выиграно к решённым (КП в работе не считаются) |
| Объём | сумма выигранных КП в рублях по текущему курсу |
| Договоры | подписано из заведённых |
| Платежи | оплачено и просрочено, ниже — доля вовремя |
| КП → договор | средний срок от отправки до подписания |
| Скидка | средневзвешенный процент партнёру и заказчику |

**Балл** = конверсия (вес 40) + объём относительно лучшего партнёра выборки (25)
+ платёжная дисциплина (25) − штраф за скидку партнёру (10), обрезано до 0–100.

Объём нормируется на лучшего в выборке, а не на рублёвый порог: одинаково
честного для всех абсолютного порога не бывает. Партнёру без платежей
дисциплина ставится нейтральной (50), чтобы новый партнёр не проваливался в E
только за то, что у него ещё нет истории.

Буквы: A ≥ 80 «Опора», B ≥ 65 «Надёжный», C ≥ 50 «Рабочий», D ≥ 35 «Слабый»,
дальше E «Требует внимания». Веса и пороги — константы в
`PartnerScoringService`.

## Проверка после установки

- [ ] `/analytics/discounts` открывается, показатели не пустые
- [ ] совокупный процент в строке сходится с карточкой КП
- [ ] КП со скидкой выше 40% подсвечено и объяснено текстом
- [ ] отбор по партнёру, году и статусу работает, «только выделенные» сокращает список
- [ ] `/analytics/partners` открывается, партнёры отсортированы по баллу
- [ ] конверсия и объём совпадают с ожиданиями по знакомому партнёру
- [ ] пункты меню появились, доступ выдаётся в настройках прав

# patch v40 — воронка продаж без сделок Wei Wei и Александра Суханова

Ставится поверх v39. Решение владельца 25.09.2026: на странице «Воронка продаж» (`/bitrix/dashboard`)
сделки двух менеджеров не учитываются ни в одной таблице и ни в одной детализации. **Только воронка:**
реестр сделок, выгрузка реестра, рабочий стол и прочие разделы считают всех, как раньше.

Менеджеры заданы id пользователя Битрикс24 из поля `assigned_by` (имя может смениться):

| id | Менеджер | Сделок на проде (все стадии, 25.09) |
|---|---|---|
| 191 | Александр Суханов | 21 |
| 195 | Wei Wei | 4 |

Список — константа `DashboardDataService::EXCLUDED_MANAGERS`; чтобы вернуть менеджера, строку убрать.

## Файлы

- `app/Modules/Bitrix/Dashboard/Services/DashboardDataService.php` — константа `EXCLUDED_MANAGERS`,
  `isExcluded()`, `withoutExcluded()`; третий параметр конструктора `$exclude` (по умолчанию — как `$filtered`:
  страница воронки убирает, вызовы рабочего стола с `filtered = false` — нет). Исключение применено к общему
  срезу сделок и к пяти таблицам, которые выбирают сделки заново (`CrmDeal::all()`): страны × статусы
  поквартально, менеджеры × статусы, страны × статусы и статусы × страны помесячно, `anna_text`.
  «Отрасли» пересекают сделки с общим срезом через `filter()` — исключаются через него.
- `app/Modules/Bitrix/CrmDeal/Repositories/CrmDealRepository.php` — `getFilterOptions()` (только попап фильтра
  воронки): двух менеджеров нет в списке «Ответственный».
- «Сделки с ошибками» (кнопка на странице воронки, решение владельца 25.09 — тоже без них):
  `CrmDealRepository::getDealWithIssues(bool $exclude = false)`; с `true` вызывают `DashboardController::index`
  (счётчик на кнопке), `CrmDealBoxController::issues` (попап `/bitrix/deal/box/issues`, открывается только с воронки)
  и компонент `DealIssues` (в шаблоне закомментирован). Виджет стола «Сделки с ошибками» вызывает без параметра — всех.
- `app/Modules/Pub/Desktop/Widgets/Funnel/FunnelTableWidget.php` — виджет «Таблица воронки» в режиме «с фильтром
  страницы» передаёт `$exclude = false`: рабочий стол не меняется.

Что покрыто: карточки сумм (сделки, лицензии, услуги, разработка, платформа, чистые услуги) и их попапы, «Отрасли»
(таблица, график, попап), четыре матрицы и их попапы, фильтр, Excel/PDF-выгрузки таблиц воронки
(`report/download/tbl_*`, `ReportDownloadService` — тот же сервис по умолчанию). Карточка «Продление лицензий»
берёт ключи лицензий, не сделки, — не затронута.

Миграций, стилей и правок `config/modular.php` нет. База не меняется.

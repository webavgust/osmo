# patch v47 — договоры на карточке партнёра

Ставится поверх v46. Вкладка «Договоры» на `/partners/detail/{id}`: вместо одной общей таблицы каждый договор — своя
карточка. Макет одобрен владельцем 06.11.2026 (на данных партнёра СТК, `patches/patch-v47/mockup-partner-21.png`).

## Что поменялось

- **Группировка по нашему юрлицу.** Сверху блок «OSMOVIEW», ниже «NEIROLIS» (порядок — `organization_id`), у заголовка
  число договоров и сумма. Договор без юрлица попадает в блок «Юрлицо не указано» в конце. Юрлицо из строки договора убрано.
- **Порядок внутри юрлица:** ПО → Платформа → Услуги → Разработка → Партнёрское соглашение → прочие, внутри типа — свежие выше.
- **Карточка договора:** шапка — тип с иконкой, номер, дата, «Подписан» / «Не подписан», сумма договора, кнопки
  «редактировать», «добавить спецификацию» и стрелка сворачивания. Ниже — таблица спецификаций со своими заголовками,
  спецификации сгруппированы по компании-клиенту, как раньше. Строки спецификаций и оплат не менялись.
- **Свёрнутые закрытые.** Договор, у которого все спецификации в статусе «Закрыта» или «Отменена», открывается свёрнутым
  до шапки с пометкой «все спецификации закрыты». Развернуть — клик по шапке или стрелке; кнопка «Развернуть закрытые (N)»
  над списком разворачивает и сворачивает их все. Договор без спецификаций не сворачивается, в нём ссылка «добавить».
- **Ссылка на спецификацию** (`#spec_ID`, из карточки сделки) разворачивает свёрнутый договор и подсвечивает строку, как раньше.
- Над списком — число договоров партнёра и общая сумма по валютам, кнопка «Добавить договор» (была плюсом в шапке таблицы).

## Файлы

- `resources/views/themes/metronic/pub/partner/detail.blade.php` — разметка вкладки «Договоры», стили (`@section('content')`),
  скрипт сворачивания (`@section('js')`).

Новых модулей, маршрутов и миграций нет, `config/modular.php` не менялся.

## Что сделать руками при выкатке

1. `git pull`, очистка кеша вьюх от www-root: `runuser -u www-root -- php artisan view:clear`.
2. Проверить, что в `storage` и `bootstrap/cache` нет файлов root (см. память о выкатке).

## discounts — Скидки

Правки: вьюха `discounts.blade.php` (переписана), `sample()` в `DiscountsWidget` (7 строк по грейдам
вместо 5; при разбивке «КП с самой большой скидкой» — столько КП, сколько в настройке `limit`),
стили в файле группы.

### Поведение по размерам
- ширина 2 (любая высота 2): подпись «скидка» и средняя скидка; период — в `title`;
- ширина ≥6 (≥230 px): в подписи добавляется период («средняя скидка: 2026 год»);
- высота ≥4 (3–5 ячеек): макс. скидка, флажок выделенных КП, «отдано скидками» (на узком — только сумма);
  при ширине 2–5 разбивка списком под показателями, при ширине ≥6 — **сбоку** от показателей
  (список, с ширины 12 — таблица), строки режутся `.desk-fit` (`data-fit-min="0"`);
- высота ≥6 при ширине ≥6 и любая высота ≥10: показатели плитками (макс., выделено, КП, отдано),
  в строках списка — вторая строка «N КП · описание грейда»;
- ширина ≥12: таблица «грейд / КП / шкала (≥420 px) / %», с 620 px — колонка описания
  (партнёра для разбивки по КП); у разбивки по КП колонки «КП» нет;
- высота ≥10 при ширине ≥4: число крупнее (`desk-value-lg`); выше 560 px строки списка и таблицы
  просторнее, чтобы высокий блок не пустовал;

# Прогон по сетке: группа «Финансы» (finance)

Стили группы — `public/metronic/css/osmo-desktop-widgets/finance.css`. Общие приёмы группы:
`.fin-line` — строка итогов в одну линию с подгоном по ширине (`.desk-fit` + `data-fit-axis="x"`,
что не влезло — прячется целиком); `.fin-list` + `.fin-amount` — список, который в самом узком
блоке (≤120 px) переносит название над датой и суммой.

Коды во всех матрицах: T в столбцах ширины 2 и 4 при высоте 2 — это заголовок виджета в
оболочке (`.desk-widget-title`, теперь с `title`), вьюха на него не влияет.

- «и ещё N» под списками считает только строки, спрятанные подгоном по высоте; если данных
  больше, чем `limit`/`MAX_ROWS` (например, 45 неподписанных договоров при 30 строках), остаток
  в подпись не попадает — полное число видно только в итогах сверху. Для живых данных сейчас
  неактуально (6 договоров, 31 расхождение при 30 строках — «и ещё» на 1 меньше).

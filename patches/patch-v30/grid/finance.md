# Прогон по сетке: группа «Финансы» (finance)

Стили группы — `public/metronic/css/osmo-desktop-widgets/finance.css`. Общие приёмы группы:
`.fin-line` — строка итогов в одну линию с подгоном по ширине (`.desk-fit` + `data-fit-axis="x"`,
что не влезло — прячется целиком); `.fin-list` + `.fin-amount` — список, который в самом узком
блоке (≤120 px) переносит название над датой и суммой.

Коды во всех матрицах: T в столбцах ширины 2 и 4 при высоте 2 — это заголовок виджета в
оболочке (`.desk-widget-title` без `title`), вьюха на него не влияет.

## Неподписанные договоры — `contracts_unsigned`

Правки: список и таблица — `$rows_max` в `.desk-fit` вместо `.desk-scroll`; итоги строками с
подгоном по ширине; разбивка по давности (`ages` в `data()`, полоска `.desk-split`); настройка
«Сколько договоров» по умолчанию — `MAX_ROWS` (30), то есть сколько влезет по высоте;
`sample()` на 30 договоров; номер договора в таблице больше не режется многоточием.

**Поведение по размерам**

  `.desk-hide-narrow`, сумма — подгоном строки);

- высота 2–4 (`$rows` < 5): только итоги; при высоте ≥4 — строка бейджей «дольше всех /

- высота ≥5: + список договоров до `$rows_max` (`.desk-fit`, подпись «и ещё N»):

## Оплаты: план и факт — `payment_summary`

Правки: плитки — сетка на 1/2/4 колонки по ширине блока (`.ps-tiles`), кегль числа в плитке
считается от колонки (`.ps-num`, `clamp()` в `cqw`/`cqh`), а не от всего блока — раньше суммы
в плитках уходили в многоточие; плитки, не влезшие по высоте, прячет `.desk-fit`; в `data()`
добавлен ряд `series` (план и факт по дням / неделям / месяцам периода — корзины из
`PaymentsFactWidget::buckets()`), по нему график в крупном блоке; в самом узком блоке —
столбик исполнения на всю высоту. `sample()` отдаёт ряд по неделям текущего квартала.

**Поведение по размерам**
- ширина 2: процент исполнения; высота ≥3 — + «факт 6,8 / млн ₽» в две строки;
  `$rows` ≥ 5 — + вертикальный столбик исполнения на всю оставшуюся высоту;
- высота 2 (ширина ≥4): «исполнение» и строка «79,5 % · факт 6,8 млн ₽ · −1,8 млн ₽»,
  что не влезло по ширине — спрятано; период в подписи — от 230 px;
- высота ≥3: плитки «план / факт / исполнение / отклонение» (ширина 4 — в столбик, 6–11 — по две,
  ≥560 px — в ряд) и строка «ждём ещё · просрочено · без курса»; высокий блок (≥230 px) —

# WIKI портала OSMO — пакет для развёртывания

Версия от 15.09.2026. Раздел корпоративной вики с руководством пользователя портала OSMO.
Его читают сотрудники и корпоративная LLM, которая по этим страницам отвечает на вопросы
вроде «где найти отчёт по партнёрам».

## Состав пакета

| Файл | Что это |
|---|---|
| `README.md` | главная страница раздела: оглавление, карта меню портала, схема данных |
| `00-glossary.md` … `15-faq.md` | 16 страниц руководства; номер в имени задаёт порядок |
| `img/` | 28 скриншотов PNG, на которые ссылаются страницы |
| `index.html`, `_sidebar.md` | только для предварительного просмотра (см. ниже), в вики не переносить |
| `DEPLOY.md` | этот файл, в вики не переносить |

## Что учесть при переносе

1. **Формат** — Markdown в диалекте GitHub: таблицы, списки, выделение. Кодировка UTF-8.
2. **Ссылки между страницами** — относительные имена файлов: `[КП](03-proposals.md)`. Если вики
   хранит страницы под другими адресами, замените ссылки по таблице выше (файл → заголовок).
   Ссылок на внешние сайты в тексте нет.
3. **Картинки** — `![подпись](img/имя.png)`. Загрузите папку `img/` во вложения раздела и поправьте
   пути, если вики хранит вложения иначе. Подпись объясняет, зачем смотреть на кадр, — её сохраните.
4. **Схемы Mermaid** — блоки ` ```mermaid ` в шести файлах: `README.md`, `03-proposals.md`,
   `06-deal-projects.md`, `09-contracts-payments.md`, `12-references.md`, `14-entity-log.md`.
   Если вики не рисует Mermaid, включите его поддержку (GitLab и GitHub рисуют без настроек) или
   замените блок картинкой, отрисованной из того же кода, например на mermaid.live.
5. **HTML-таблицы с объединёнными ячейками** (`rowspan`) — в `README.md` (раздел «Карта меню
   портала») и `01-interface.md` («Найти нужный раздел»). Если вики не принимает HTML внутри
   Markdown, пересоберите эти две таблицы редактором вики: объединены ячейки разделов меню,
   в `01-interface.md` — ещё и повторяющиеся ссылки на страницы.
6. **Адреса страниц портала** в тексте записаны кодом, без домена: `/proposals`. Это ориентир
   для сотрудника; при желании их можно сделать ссылками, дописав адрес портала.

## Доступ

- Руководство для сотрудников; административная часть портала в нём не описана.
- Скриншоты сняты с рабочих данных: на них видны названия партнёров и компаний, суммы, имена
  сотрудников и учётная запись в меню портала. Публикуйте раздел только во внутренней вики,
  доступной сотрудникам компании.

## Для корпоративной LLM

- Страницы самодостаточны и устроены одинаково: «Где найти» → задачи с заголовками-действиями
  (`## Привязать КП к сделке`) → «Как это устроено» → «Частые вопросы».
- Индексировать удобно по разделам `##`: один раздел — одна задача или одно правило. В метаданных
  фрагмента сохраняйте заголовок страницы, чтобы ответ мог на неё сослаться.
- «Частые вопросы» на страницах и `15-faq.md` — готовые пары «вопрос — ответ», `00-glossary.md` —
  определения терминов.
- Картинки для LLM не нужны: всё важное есть в тексте.

## Предварительный просмотр

Пакет открывается в браузере как есть, до переноса в вики:

```bash
cd osmo-wiki
python -m http.server 8124
```

Затем откройте http://localhost:8124 — страницы с картинками, схемами, поиском и боковым меню.
`index.html` загружает просмотрщик docsify и Mermaid с cdn.jsdelivr.net, поэтому нужен доступ
в интернет. Ту же папку можно выложить на любой статический веб-сервер как отдельный сайт
руководства.

## Обновления

Источник текста — репозиторий портала, каталог `docs/wiki/`. Новая версия пакета приходит целиком:
страницы заменяются по имени файла, картинки — по имени в `img/`. Картинки, которых нет в новом
пакете, удалите и из вложений вики.

## Файлы

- `fix_companies.php` — сценарий. Сверяет исходное состояние и при расхождении ничего не делает, поэтому
  повторный запуск безопасен (он просто остановится). По умолчанию — пробный прогон с откатом, `--apply` —
  выполнить. Запуск: `runuser -u www-root -- php -- --apply < fix_companies.php` из корня сайта.
- `app/Modules/Pub/Company/Models/Company.php` — блок оплат на карточке компании считается по
  спецификациям заказчика (свои + спецификации его договоров без своей компании), как в платёжном
  календаре. Без этого у ЦОДД и Метро блок оплат пустой: договоры-рамки заказчика не хранят.
  **Выкатывается обычным `git pull`.**

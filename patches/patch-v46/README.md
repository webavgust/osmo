# patch v46 — генератор номеров договора

Ставится поверх v45. Заменяет ручную нумерацию в Google-таблице договоров.

## Что поменялось

- **Формы создания и редактирования договора**: новое поле «Менеджер» и кнопка-иконка рядом с номером.
  Кнопка подставляет номер в поле, записывается он при сохранении формы. При создании менеджер по умолчанию —
  текущий пользователь.
- **Формат номера** — как в таблице: `L-AA-65/11.26` — тип, инициалы менеджера (`users.initials`), порядковый
  номер, месяц и год из поля «Дата договора» (если пусто — сегодня).
- **Порядковый номер** сквозной: наибольший среди договоров формата `…-N/месяц.год` + 1, но не меньше 65
  (`ContractService::LAST_SHEET_SEQUENCE = 64` — последний номер таблицы). Опечатки без косой черты
  (`L-AK-511.26`) не считаются. Номер не резервируется: занятым становится после сохранения.
- **Новые типы:** `partnership` (PA, «Партнёрское соглашение», зелёный, рукопожатие) выбирается в формах;
  `development` (D, «Разработка») пока скрыт — чтобы включить, убрать `hidden` в `ContractType`.
- **Занятый номер не сохраняется:** проверка в транзакции с блокировкой строк (`ContractService::numberConflict`) —
  нельзя сохранить тот же номер или тот же порядковый. Неизменённый номер не проверяется: в базе есть старые повторы
  (`L-PG-26/5.25` и `P-АА-26/10.2024`). Текст ошибки показывается в форме.
- **Редактирование больше не отвязывает КП:** форма не передаёт поле `proposal`, из-за этого каждое сохранение
  очищало `proposal_id` и меняло `uuid`. Теперь они меняются, только если поле передано. Уже потерянные привязки
  не восстанавливаются.
- **Инициалы Натальи Кручининой:** на проде `users.initials` у id 7 исправлены с `RK` на `NK`.
- **Журнал изменений** договора показывает смену менеджера.

## Что сделать руками при выкатке

1. Копия БД: `php patches/deploy-v21-v32/backup_db.php /root/backup`.
2. `git pull`, `php artisan migrate --force`, очистка кеша от www-root, `chown` кеша (см. память о выкатке).
3. Менеджеры по существующим номерам: `php patches/patch-v46/tools/backfill_contract_managers.php` (пробный
   прогон), затем то же с `--apply`. Заполняются только пустые `manager_id`, сами номера не меняются, записи
   журнала не создаются.
4. Инициалы: `users.initials = 'NK'` у id 7 (только если сейчас `RK`).

## Чек-лист

- [ ] Создание: выбрать тип, нажать кнопку — в поле `L-AA-65/11.26`.
- [ ] Без типа или менеджера — сообщение об ошибке, номер не меняется.
- [ ] Дата договора 15.03.2026 → в номере `/3.26`.
- [ ] Сохранить договор — следующий номер на единицу больше.
- [ ] Редактирование: у скрытого менеджера (Головин) имя остаётся в списке.
- [ ] Редактирование договора с КП: привязка к КП сохраняется.
- [ ] Занятый номер при сохранении — сообщение «Порядковый номер занят…», договор не меняется.
- [ ] В списке «Тип» есть «Партнёрское соглашение», номер `PA-AA-65/11.26`.

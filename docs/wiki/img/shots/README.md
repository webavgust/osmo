# Спецификации кадров

Один файл на страницу руководства, формат кадра — в шапке `patches/wiki-tools/shot.js`.
Съёмка всех кадров с локального портала:

```bash
node <shots>/shot.js docs/wiki/img/shots docs/wiki/img --vars=PARTNER=13,COMPANY=37,PROPOSAL=43428550-5403-45e5-8d5f-aa9da1c6cd54,PROPOSAL_ID=ef028595-a2cd-43a7-a843-315a7c44ff9e,KEY=ef028595-a2cd-43a7-a843-315a7c44ff9e,DATE=2026-09-01,DEAL=885,SCENARIO=1,DESK=20
```

Плейсхолдеры в `url` и селекторах:

| Плейсхолдер | Что подставить | Как выбирали 15.09.2026 |
|---|---|---|
| `{PARTNER}` | id партнёра с договорами, спецификациями и сделками | партнёр с наибольшим числом спецификаций |
| `{COMPANY}` | id компании с ключами и спецификациями | компания с наибольшим числом ключей |
| `{PROPOSAL}` | group (uuid) КП с несколькими вариантами и сделкой | КП с 5 вариантами |
| `{PROPOSAL_ID}`, `{KEY}` | group КП с длинным журналом изменений | КП с наибольшим числом событий журнала |
| `{DATE}` | дата для «состояния на дату» | `2026-09-01` |
| `{DEAL}` | id сделки Битрикс24 с привязанным КП | сделка из `{PROPOSAL}` |
| `{SCENARIO}` | id любого сценария | первый по порядку |
| `{DESK}` | id стола для кадров рабочего стола | временный стол «WIKI (кадры документации)», создаётся и удаляется скриптом `wiki_desk.php` (см. `patches/wiki-tools/`) — стол владельца не трогать |

Кадры режима редактирования стола (`desktop-04…09`) снимаются на ширине 1920: на 1440
сетка переключается на меньшее число колонок и редактирование недоступно.

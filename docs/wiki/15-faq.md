# FAQ: где найти и как сделать

Короткие ответы на типовые вопросы сотрудников. Каждый ответ ведёт на страницу руководства,
где описание подробнее. Пути даны от левого меню портала: «Раздел» → «Пункт».

## Где найти …

| Вопрос | Ответ | Подробнее |
|---|---|---|
| … отчёт по партнёрам? | «Отчёты» → «Скоринг партнёров» (`/analytics/partners`): таблица партнёров с баллом, КП, сделками, проектами, договорами и платежами. Подробности по партнёру — кнопка «По годам» в его строке. | [11-reports.md](11-reports.md) |
| … скоринг партнёра и как он считается? | Там же; балл и буква A–E в первой колонке, формула и веса — значок «?» в шапке страницы. | [11-reports.md](11-reports.md) |
| … список всех КП? | «Работа» → «КП» (`/proposals`). Фильтр по партнёру, компании, статусу, дате, сделке — кнопка «Фильтр». | [03-proposals.md](03-proposals.md) |
| … КП конкретного партнёра или компании? | «Работа» → «КП» → «Фильтр» → «Партнёр» / «Компания», либо блок КП на карточке компании. | [03-proposals.md](03-proposals.md), [07-partners.md](07-partners.md), [08-companies.md](08-companies.md) |
| … КП, не привязанные к сделке? | «Работа» → «КП» → «Фильтр» → «Сделка Битрикс24» → «Не привязана». | [03-proposals.md](03-proposals.md) |
| … КП из внешнего генератора OSMOVIEW CP? | «Работа» → «Внешние КП» (`/external-proposals`). | [04-external-proposals.md](04-external-proposals.md) |
| … сделки Битрикс24? | «Работа» → «Реестр сделок Битрикс24» (`/bitrix/deal`); сделки одного партнёра — вкладка «Сделки Битрикс24» на его карточке. | [05-bitrix-deals.md](05-bitrix-deals.md), [07-partners.md](07-partners.md) |
| … воронку продаж по стадиям, странам и менеджерам? | «Работа» → «Воронка продаж» (`/bitrix/dashboard`). | [05-bitrix-deals.md](05-bitrix-deals.md) |
| … проекты по сделкам? | Значок проекта в реестре сделок; вкладки «Проекты» и «Архив проектов» на карточке партнёра; виджет «Проекты по сделкам» на рабочем столе. | [06-deal-projects.md](06-deal-projects.md) |
| … партнёра / компанию? | «Справочники» → «Партнёры» (`/partners`), «Справочники» → «Компании» (`/companies`). Поиск — поле «Поиск» над таблицей. | [07-partners.md](07-partners.md), [08-companies.md](08-companies.md) |
| … договоры и спецификации партнёра? | Карточка партнёра → вкладка «Договоры». | [09-contracts-payments.md](09-contracts-payments.md) |
| … отчёт по договорам и оплатам? | «Отчёты» → «Договоры и оплаты» (`/report/payments`); выгрузка в Excel — значок Excel справа вверху. | [09-contracts-payments.md](09-contracts-payments.md) |
| … план поступлений по месяцам и просроченные платежи? | «Отчёты» → «Платёжный календарь» (`/payment-calendar`). | [09-contracts-payments.md](09-contracts-payments.md) |
| … оплаты конкретной спецификации? | Карточка партнёра → «Договоры» → значок монет «Управление оплатами» в строке спецификации. | [09-contracts-payments.md](09-contracts-payments.md) |
| … лицензионные ключи? | Карточка компании → блок «Лицензионные ключи»; сводно — «Отчёты» → «Ключи» (`/report/license_keys`). | [10-licenses.md](10-licenses.md) |
| … лицензии, которые скоро истекают? | «Отчёты» → «Реестр лицензий» (`/analytics/licenses`), горизонт 30/60/90 дней; виджет «Истекающие ключи» на рабочем столе. | [10-licenses.md](10-licenses.md) |
| … анализ скидок в КП? | «Отчёты» → «Анализ скидок» (`/analytics/discounts`). | [11-reports.md](11-reports.md) |
| … расхождения между порталом и Битрикс24? | «Отчёты» → «Расхождения с Битрикс24» (`/crm-monitor`). | [11-reports.md](11-reports.md) |
| … что входит в спецификацию (конфигурации, состав)? | «Отчёты» → «Конфигурации, сводная» (`/report/specs`). | [11-reports.md](11-reports.md) |
| … какие сценарии куплены клиентом? | «Отчёты» → «Сценарии по спецификациям» (`/report/scenarios_specs`). | [11-reports.md](11-reports.md) |
| … отчёт для Китая? | «Отчёты» → «Китай» (`/report/china`) → «Скачать отчёт». | [11-reports.md](11-reports.md) |
| … справочники сценариев, нейросервисов, работ, ПО? | Раздел «Справочники»: «Нейросервисы», «Сценарии», «Работы», «ПО». | [12-references.md](12-references.md) |
| … цену сценария или нейросервиса? | «Справочники» → «Сценарии» / «Нейросервисы» → «Редактировать» → таблица «Стоимость». | [12-references.md](12-references.md) |
| … кто и когда менял КП, партнёра, компанию? | Кнопка «Журнал изменений» в шапке карточки (нужно право «Видит журнал изменений»). | [14-entity-log.md](14-entity-log.md) |
| … как выглядело КП на прошлую дату? | В журнале изменений — «Состояние на конец дня» у нужной даты. | [14-entity-log.md](14-entity-log.md) |
| … историю цен КП? | Карточка КП → меню «⋮» → «История изменения цен». | [03-proposals.md](03-proposals.md) |
| … сводку по сделке: КП, спецификации, оплаты, лицензии? | Карточка КП → кнопка «Сводная информация» (нужно право на сводную карточку сделки). | [03-proposals.md](03-proposals.md) |
| … мой профиль, календарь, напоминания, уведомления? | Клик по аватару в левом меню → подменю профиля. | [13-personal.md](13-personal.md) |
| … старые уведомления? | Аватар → «История уведомлений» (`/notify/list`). | [13-personal.md](13-personal.md) |
| … мои заметки? | Виджет «Блокнот» на рабочем столе. | [13-personal.md](13-personal.md), [02-desktop.md](02-desktop.md) |
| … главную страницу с показателями? | «Работа» → «Рабочий стол» (`/desktop`) — собирается из виджетов под себя. | [02-desktop.md](02-desktop.md) |

## Как сделать …

| Вопрос | Ответ | Подробнее |
|---|---|---|
| … создать КП? | «Работа» → «КП» → «Создать КП»: менеджер, партнёр и компания, варианты и позиции. | [03-proposals.md](03-proposals.md) |
| … сделать новую версию КП, не теряя старую? | Карточка КП → «⋮» → «Редактировать» с флажком «Создать новую версию» — появится новая редакция. | [03-proposals.md](03-proposals.md) |
| … получить КП в PDF или Excel? | Карточка КП → «⋮» → «Создать PDF» / «Создать Excel». | [03-proposals.md](03-proposals.md) |
| … пересчитать КП в другую валюту? | Карточка КП → «⋮» → «Конвертировать в валюту» — создаётся новая редакция по курсу. | [03-proposals.md](03-proposals.md) |
| … привязать КП к сделке Битрикс24? | Из списка КП или карточки — окно привязки сделки; из реестра сделок — кнопка привязки КП в строке сделки. | [03-proposals.md](03-proposals.md), [05-bitrix-deals.md](05-bitrix-deals.md) |
| … перенести внешнее КП в портал? | «Работа» → «Внешние КП» → «Перенести» в строке; сопоставьте сценарии и подтвердите. | [04-external-proposals.md](04-external-proposals.md) |
| … создать проект по сделке? | «Работа» → «Реестр сделок Битрикс24» → «+ проект» в строке сделки. | [06-deal-projects.md](06-deal-projects.md) |
| … выгрузить сделки в Excel? | «Реестр сделок Битрикс24» → «Действия» → «Выгрузить в Excel»; в файл попадут сделки текущей вкладки и фильтра. | [05-bitrix-deals.md](05-bitrix-deals.md) |
| … сопоставить партнёра с компанией Битрикс24? | Карточка партнёра → «Редактировать» → поле «Компании в Битрикс24». Без этого у партнёра нет сделок и скоринга. | [07-partners.md](07-partners.md) |
| … завести договор и спецификацию? | Карточка партнёра → «Договоры» → «+» («Добавить договор»), затем «+» у договора для спецификации. | [09-contracts-payments.md](09-contracts-payments.md) |
| … заполнить график оплат? | Строка спецификации → значок монет «Управление оплатами» → плановые платежи с датами; факт отмечается там же. | [09-contracts-payments.md](09-contracts-payments.md) |
| … прикрепить КП к спецификации? | Значок цепочки «Прикрепление КП» в строке спецификации; КП в работе станет «Выиграно». | [09-contracts-payments.md](09-contracts-payments.md) |
| … завести лицензионный ключ? | Карточка компании → «+» в блоке «Лицензионные ключи» → «Прикрепление ключа». | [10-licenses.md](10-licenses.md) |
| … отметить продление лицензии? | Заведите новый ключ с новыми датами и снимите «Активный» у старого. | [10-licenses.md](10-licenses.md) |
| … добавить виджет на рабочий стол? | «Рабочий стол» → «Редактировать» → «Библиотека» → «Добавить» у виджета → «Сохранить». Нужен широкий экран. | [02-desktop.md](02-desktop.md) |
| … изменить размер виджета? | В режиме редактирования потяните за уголок или нажмите на него и выберите размер на панели «Размеры». | [02-desktop.md](02-desktop.md) |
| … сменить валюту и период на столе? | Виджеты «Выбор валюты» и «Период» на столе; чтобы выбор запомнился — «Редактировать» → «Сохранить». | [02-desktop.md](02-desktop.md) |
| … создать напоминание себе или коллеге? | Аватар → «Напоминания» → «+»; коллеге — поле «Для кого», оно есть только у руководителя. | [13-personal.md](13-personal.md) |
| … добавить событие в календарь? | Аватар → «Календарь» → «Добавить событие». | [13-personal.md](13-personal.md) |
| … включить тёмную тему? | Аватар → «Цветовая схема» → «Тёмная». | [01-interface.md](01-interface.md) |
| … найти строку в большой таблице? | Поле «Поиск» над таблицей; связи (партнёр, статус, даты) — кнопка «Фильтр». | [01-interface.md](01-interface.md) |

## Почему …

| Вопрос | Ответ | Подробнее |
|---|---|---|
| … у меня нет раздела «Настройки», кнопки «Журнал изменений» или «Сводная информация»? | Эти части видны только с соответствующим правом; права выдаёт администратор портала. | [01-interface.md](01-interface.md) |
| … у партнёра ноль сделок и «нет сопоставления» в скоринге? | Не заполнено поле «Компании в Битрикс24» в форме партнёра. | [07-partners.md](07-partners.md) |
| … статус КП сам стал «Выиграно»? | КП в работе прикрепили к спецификации договора — статус ставится автоматически. | [09-contracts-payments.md](09-contracts-payments.md) |
| … у спецификации нулевая сумма? | Сумма спецификации складывается из плановых платежей — заполните «Управление оплатами». | [09-contracts-payments.md](09-contracts-payments.md) |
| … КП выделено красным в «Анализе скидок»? | Скидка выше 40 % или больше средней по грейду партнёра более чем на 5 п.п. | [11-reports.md](11-reports.md) |
| … ключ подсвечен красным или оранжевым? | Красный — срок действия истёк, оранжевый — истекает в ближайшие три месяца. | [10-licenses.md](10-licenses.md) |
| … не включается редактирование рабочего стола? | Открыт системный пресет или чужой стол, либо экран слишком узкий. | [02-desktop.md](02-desktop.md) |
| … напоминание не удаляется? | Оно уже сработало; такие напоминания удалить нельзя. | [13-personal.md](13-personal.md) |
| … в таблице не все строки? | Включён фильтр (число у кнопки «Фильтр») или выбрана вкладка менеджера; увеличьте число строк на странице. | [01-interface.md](01-interface.md) |

# Глоссарий портала OSMO

Термины в том значении, в каком они используются на экранах портала. Страницы
wiki ссылаются сюда при первом упоминании термина.

| Термин | Что означает | Где в портале |
|---|---|---|
| **Вариант КП** | Один из вариантов комплектации внутри итерации: свой набор сценариев, работ, ПО, платформ и оборудования и своя итоговая цена. | Карточка КП |
| **Виджет** | Блок на рабочем столе: показатель, график, список или быстрая ссылка. Размер и настройки задаются пользователем. | Рабочий стол, библиотека виджетов |
| **Внешнее КП** | КП, сделанное во внешнем генераторе OSMOVIEW CP и полученное порталом автоматически. Его можно перенести во внутреннее КП. | «Работа» → «Внешние КП», [04-external-proposals.md](04-external-proposals.md) |
| **Грейд партнёра** | Уровень партнёрства (Agent, Silver, Bronze, Platinum и др.), показывается значком-медалью. | Список и карточка партнёра |
| **Договор** | Договор с партнёром. К договору привязываются спецификации. | Карточка партнёра, [09-contracts-payments.md](09-contracts-payments.md) |
| **Дополнительные сборы** | Надбавки к варианту КП (доставка, налоги, наценки), не входящие в прайс. | Карточка КП |
| **Журнал изменений** | Лента правок сущности (КП, партнёра, компании, спецификации, проекта): кто, когда и что изменил; у части сущностей можно посмотреть состояние на дату. | Кнопка «Журнал изменений» на карточках, [14-entity-log.md](14-entity-log.md) |
| **Итерация КП** | Версия одного и того же КП. Каждая правка, которую нужно сохранить как отдельную версию, создаёт новую итерацию; старые остаются для истории. Номер КП у всех итераций общий. | Карточка КП, панель итераций |
| **Компания** | Конечный заказчик — организация, на объектах которой работает решение. Привязана к партнёру, стране и сектору (отрасли). | «Справочники» → «Компании», [08-companies.md](08-companies.md) |
| **КП** (коммерческое предложение) | Расчёт стоимости решения для заказчика: набор вариантов с ценами. Имеет номер (например `AA787`), партнёра, компанию-заказчика, менеджера, валюту, язык, статус. | «Работа» → «КП», [03-proposals.md](03-proposals.md) |
| **Лицензионный ключ** | Ключ активации ПО, выданный компании: номер, продукт, срок действия, количество. | Карточка компании, отчёт «Ключи», [10-licenses.md](10-licenses.md) |
| **Менеджер** | Сотрудник, ответственный за КП или сделку. По менеджеру фильтруются списки и строится воронка. | Списки КП и сделок |
| **Нейросервис** | Аналитический модуль видеоаналитики (детекция людей, контроль СИЗ и т. п.), объединяет сценарии. | «Справочники» → «Нейросервисы», [12-references.md](12-references.md) |
| **Оборудование** | Железо в варианте КП: серверы, камеры и т. п., с ценой и количеством. | Карточка КП |
| **Оплата** | Плановый или фактический платёж по спецификации с датой и суммой. Просроченная оплата — плановая, срок которой прошёл без факта. | Контроль оплат, «Платёжный календарь» |
| **Партнёр** | Контрагент-интегратор или дистрибьютор, через которого идут продажи: с ним заключаются договоры, ему выставляются КП. У партнёра есть грейд (уровень) и тип. | «Справочники» → «Партнёры», [07-partners.md](07-partners.md) |
| **ПО** | Программный продукт из прайса (лицензии, платформа), добавляется в вариант КП. | «Справочники» → «ПО» |
| **Попап** | Окно поверх текущей страницы: формы создания и правки, детали записи. Закрывается крестиком или кнопкой «Отмена». | Везде |
| **Привязка КП к сделке** | Связь между КП портала и сделкой Битрикс24. У КП может быть несколько сделок, одна из них — главная. | Карточка и список КП, реестр сделок |
| **Проект компании** и **конфигурация** | Другое понятие: описание объекта заказчика (проект компании) и набора оборудования и сценариев на нём (конфигурация). Используется при составлении спецификаций. Не путать с проектом по сделке. | Карточка компании, [08-companies.md](08-companies.md) |
| **Проект по сделке** | Выполняемый проект по выигранной сделке: название, партнёр, даты, статус, привязанные сделки и спецификации. Может быть отправлен в архив. | Реестр сделок, карточка партнёра, [06-deal-projects.md](06-deal-projects.md) |
| **Работа** | Услуга из прайса (внедрение, обучение, настройка), добавляется в вариант КП. | «Справочники» → «Работы» |
| **Рабочий стол** | Главная страница портала: набор виджетов, который каждый пользователь собирает под себя. Столов может быть несколько. | «Работа» → «Рабочий стол», [02-desktop.md](02-desktop.md) |
| **Сделка Битрикс24** | Сделка из CRM Битрикс24, копия которой хранится в портале. У сделки есть стадия, менеджер, партнёр (компания в Битрикс24), заказчик, сумма. Портал только читает сделки, править их нужно в Битрикс24. | «Работа» → «Реестр сделок Битрикс24», [05-bitrix-deals.md](05-bitrix-deals.md) |
| **Скоринг партнёров** | Рейтинг партнёров в баллах (0–100) по подписанным спецификациям, проектам, конверсии КП, числу сделок и просрочкам, с буквенной оценкой A–E. | «Отчёты» → «Скоринг партнёров», [11-reports.md](11-reports.md) |
| **Спецификация** | Приложение к договору на конкретную поставку: компания-заказчик, сумма, валюта, дата, признак подписания, статус. Может быть связана с КП и конфигурацией. По спецификации ведутся оплаты. | Карточка партнёра, отчёт «Договоры и оплаты» |
| **Стадия сделки** | Этап воронки в Битрикс24 (Lead … Completed / Canceled). Стадии делятся на «в работе», «выиграна», «проиграна». | Реестр сделок, воронка продаж |
| **Статус КП** | Этап жизни КП. Статусов три: в работе, выиграно, проиграно (проигранное КП имеет причину проигрыша). | Список и карточка КП |
| **Сценарий** | Конкретная аналитическая задача, которую продают в КП (единица прайса). Сценарии сгруппированы по группам и нейросервисам. | «Справочники» → «Сценарии» |
